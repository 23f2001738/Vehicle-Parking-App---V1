# Vehicle Parking App - V1

## Overview
A multi-user Flask-based web application to manage parking lots, parking spots, and parked vehicles. Supports admin and user roles with core functionalities like parking lot management, spot reservation, and status viewing.

## Requirements
- Python 3.8+
- Flask
- SQLite
